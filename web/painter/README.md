# Painter Workspace

Painter 的正式产品代码入口。当前阶段提供项目与节点画布的可运行基础层，而不是静态演示页面。

## 已实现

- 多项目创建与切换
- 提示词、参考图、笔记三类节点
- 节点新增、选择、拖拽、编辑与删除
- 画布缩放
- 项目名称和画布数据自动保存到本地
- Painter 黑白视觉基础

## 下一阶段

- 用户登录与云端项目持久化
- 图片上传与对象存储
- 节点连接、框选、分组和自动排列
- 图片生成任务 API、队列、状态和失败重试
- 资产库与版本记录
- Electron 加载本地构建产物

## 本地运行

```bash
npm install
npm run dev
```
