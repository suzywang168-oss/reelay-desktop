# Suzy Portal Desktop

Cross-platform desktop clients for three Suzy Laboratory products:

- Dip Production Portal
- Dip Admin Portal
- Painter Workspace

GitHub Actions builds separate installers for every product:

- macOS: DMG for Intel (x64) and Apple Silicon (arm64)
- Windows: NSIS EXE for x64

Download the latest installers from the **desktop-latest** GitHub Release.
